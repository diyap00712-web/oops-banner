# OOPSBannerApp

This is a simple Java application created to demonstrate Object-Oriented Programming concepts.

## Features
- Displays a banner
- Demonstrates OOP principles
- Simple and beginner friendly

## Technologies Used
- Java
- OOP Concepts

## How to Run

1. Clone the repository:
   git clone https://github.com/yourusername/oops-banner.git

2. Open in any Java IDE or VS Code.

3. Compile:
   javac OOPSBannerApp.java

4. Run:
   java OOPSBannerApp
